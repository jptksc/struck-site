# struck-site

The landing page, support and privacy pages for **Struck** — a menu-bar to-do app
for macOS that you type, and that never nags.

| Path | Page |
| --- | --- |
| `index.html` | The landing page, with a card you can actually strike |
| `support/` | Getting started, the typed grammar, keyboard shortcuts, FAQ |
| `privacy/` | The privacy policy App Store Connect points at |

Static files, no build step, no dependencies. Served by GitHub Pages from `main` —
edit a file, push, it publishes.

Every factual claim on these pages is checked against the app's own source before it
ships. The app is private; what it promises about itself is not.
